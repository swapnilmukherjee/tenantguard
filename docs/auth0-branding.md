# Auth0 Universal Login Branding

Use these settings in **Branding > Universal Login** and **Branding > Theme**.

## Assets

Production logo URL:

```txt
https://tenantguard-beryl.vercel.app/tenant-guard-logo.svg
```

Square icon/mark URL:

```txt
https://tenantguard-beryl.vercel.app/tenant-guard-mark.svg
```

If Auth0 rejects SVG for a specific branding field, export the SVG as PNG and upload the PNG instead.

## Suggested Theme

| Setting | Value |
| --- | --- |
| Primary color | `#38BDF8` |
| Page background | `#0B1220` |
| Header/background color | `#0B1220` |
| Button text color | `#0B1220` |
| Body text color | `#F8FAFC` |
